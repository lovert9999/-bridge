10 斜拉桥上部结构构件结构性缺损评定
========================================

.. raw:: html

  <h2 id="test111">10 斜拉桥上部结构构件结构性缺损评定</h2>

10.1 一般规定
----------------------

.. raw:: html

 <p style="text-align:justify"><a href="#id10.1.1"> 10.1.1</a> <span id="id10.1.1"> 斜拉桥上部结构应对主梁、斜拉索、索塔、支座及约束体系等构件进行结构性缺损评定。</span></p>
 <p style="text-align:justify;" >条文说明：<br/>支座指竖向支座。约束体系包括横向约束体系和纵向约束体系，横向约束体系指横向抗风支座、横向限位挡块等，纵向约束体系指阻尼器、纵向限位挡块等。</p>
 <p style="text-align:justify"><a href="#id10.1.2"> 10.1.2</a> <span id="id10.1.2"> 主梁设置分离式桥面板的，桥面板及其支座等构件的缺损应计入主梁缺损评定。</span></p>
 
10.2 主梁
----------------------

.. raw:: html

 <p style="text-align:justify"><a href="#id10.2.1"> 10.2.1</a> <span id="id10.2.1"> 预应力混凝土肋板梁结构性缺损评定应按本标准 <a href="06.html#id6.2.7">第6.2.7条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.2"> 10.2.2</a> <span id="id10.2.2"> 预应力混凝土箱梁结构性缺损评定应按本标准 <a href="06.html#id6.2.10">第6.2.10条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.3"> 10.2.3</a> <span id="id10.2.3"> 钢箱梁结构性缺损评定应按本标准 <a href="06.html#id6.2.12">第6.2.12条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.4"> 10.2.4</a> <span id="id10.2.4"> 钢桁梁结构性缺损评定应按本标准 <a href="06.html#id6.2.13">第6.2.13条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.5"> 10.2.5</a> <span id="id10.2.5"> 钢-混凝土组合梁结构性缺损评定应按本标准 <a href="06.html#id6.2.15">第6.2.15条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.6"> 10.2.6</a> <span id="id10.2.6"> 混凝土桥面板结构性缺损评定应按本标准 <a href="06.html#id6.2.3">第6.2.3条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.2.7"> 10.2.7</a> <span id="id10.2.7"> 钢桥面板结构性缺损评定应按本标准 <a href="06.html#id6.2.14">第6.2.14条</a>执行。</span></p>

10.4 索塔
----------------------

.. raw:: html

 <p style="text-align:justify"><a href="#id10.4.1"> 10.4.1</a> <span id="id10.4.1"> 混凝土索塔结构性缺损评定应按本标准 <a href="09.html#id9.5.1">第9.5.1条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.4.2"> 10.4.2</a> <span id="id10.4.2"> 钢索塔结构性缺损评定应按本标准 <a href="09.html#id9.5.2">第9.5.2条</a>执行。</span></p>

10.5 支座及约束体系
----------------------

.. raw:: html

 <p style="text-align:justify"><a href="#id10.5.1"> 10.5.1</a> <span id="id10.5.1"> 支座结构性缺损评定应按本标准 <a href="06.html#id6">第6.4节</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.5.2"> 10.5.2</a> <span id="id10.5.2"> 阻尼器结构性缺损评定应按本标准 <a href="09.html#id9.6.2">第9.6.2条</a>执行。</span></p>
 <p style="text-align:justify"><a href="#id10.5.3"> 10.5.3</a> <span id="id10.5.3"> 其他约束体系构件结构性缺损评定应按本标准 <a href="03.html#id3.2.2">第3.2.2条</a>确定评定标度。</span></p>
