2 术语和符号

2.1 术语

2.1.1 桥梁技术状况 bridge condition
反映桥梁构件、桥跨、全桥外观完好程度、功能保持程度和结构影响程度的综合技术指标。

2.1.2 桥梁技术状况等级 bridge condition level
反映桥跨或全桥技术状况的评定等级，以 1~5 类表示。

2.1.3 桥梁技术状况指数 bridge condition index
反映桥跨或全桥技术状况综合水平的指标，以百分制表示。

2.1.4 桥梁构件 bridge element
桥梁中独立承担或构成某项功能的最小单元，如一片梁、一个桥墩、一套伸缩装置等。

2.1.5 桥梁部件 bridge component
桥梁中同类构件的集合。

2.1.6 专项检查 special inspection
为查明构件缺损现状、发展趋势和功能异常程度，以及缺损和功能异常产生原因而开展的针对性检查。

2.1.7 构件技术状况等级 element condition level
反映桥梁构件缺损状况、功能状况、影响状况的综合评定指标，以 1~5 类表示。

2.1.8 构件缺损状况标度 element defective index
反映桥梁构件现状与原设计预期差异程度的技术指标，包括耐久性缺损和结构性缺损。

2.1.9 构件耐久性缺损 element durability defect
由初始缺陷、环境作用等引起的构件材质劣化、防护措施失效等导致构件使用年限降低的缺陷和损伤。

2.1.10 构件结构性缺损 element structural defect
由初始缺陷、直接作用或间接作用等引起的构件开裂、变形、变位、组件异常、约束状态改变等导致构件力学性能或使用功能降低的缺陷和损伤。

2.1.11 构件功能状况标度 element function index
反映构件当前状态较设计预期功能或使用需求降低程度的技术指标。

2.1.12 构件影响状况标度 element affected index
反映构件缺损发展、缺损或功能异常致灾可能或发生灾害对相关构件影响程度的技术指标。
