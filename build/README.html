主要修订要点

本标准在《公路桥梁技术状况评定标准》（JTG/T H21—2011）基础上全面修订，提出构件技术状况评定方法、细化桥型和部件划分、改进分层综合评定方法。主要修订要点：

  1. 细化评定桥型及部件组成，优化评定参数。

  2. 结合养护需求建立构件耐久性缺损和结构性缺损指标，根据构件材料和类型细化评定标度。

  3. 建立构件功能状况、影响状况的评定指标。

  4. 根据常用维修加固措施，建立维修加固构造结构性缺损的评定指标。

  5. 建立基于缺损状况、功能状况、影响状况的构件技术状况等级，提出针对构件技术状况等级的养护对策建议。

  6. 建立按构件、桥跨、全桥顺序的评定流程，改进桥梁技术状况分层综合评定方法。
