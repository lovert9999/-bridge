5 桥面系构件结构性缺损评定

5 桥面系构件结构性缺损评定

5.1 一般规定

5.1.1 桥面系应对桥面铺装、伸缩装置、防撞护栏、栏杆和人行道、排水系统等构件进行结构性缺损评定。

5.1.2 设置人行道的桥梁，栏杆和人行道应作为一个构件参与评定。

5.1.3 排水系统缺损应计入全桥各跨评定。

5.2 桥面铺装

5.2.1 沥青混凝土桥面铺装结构性缺损评定应按表5.2.1 执行。

表5.2.1 沥青混凝土桥面铺装评定
评定指标 评定标度
0 1 2 3
车辙 - 深度小于 10mm 深度介于 10 ~25mm 深度大于 25mm
波浪拥包 - 高度小于 10mm 高度介于 10 ~25mm 高度大于 25mm
坑槽 - 深度不大于 25mm，单处面积不大于 0.1m² 深度不大于 25mm，单处面积大于 0.1m² 深度大于 25mm
龟裂 面积不大于 0.04m² 单处面积大于 0.04m²；累计面积小于 0.2m² 累计面积介于 0.2 ~1m² 累计面积大于 1m²
纵向裂缝长度 - 长度小于桥跨长度的20% 长度介于桥跨长度的20% ~60% 长度大于桥跨长度的60%
横向裂缝 - 裂缝宽度小于 2mm 裂缝宽度介于 2 ~5mm 裂缝宽度大于 5mm

5.2.2 水泥混凝土桥面铺装结构性缺损评定应按表5.2.2 执行。

表5.2.2 水泥混凝土桥面铺装评定
评定指标 评定标度
0 1 2 3
磨光或露骨 - 单处面积不大于 1m²；累计面积不大于桥跨面积的 10% 单处面积大于 1m²；累计面积大于桥跨面积的 10% -
坑洞、露筋 - 坑洞深度小于 10mm 坑洞深度介于 10 ~30mm 坑洞深度大于 30mm；有露筋
裂缝 - 裂缝宽度小于 0.3mm；裂缝间距大于 3m 裂缝宽度介于 0.3 ~0.5mm；裂缝间距小于 1m 裂缝宽度大于 0.5mm；完全断裂
错台 - 高差小于 5mm 高差介于 5 ~10mm 高差大于 10mm

5.3 伸缩装置

5.3.1 橡胶式伸缩装置结构性缺损评定应按表5.3.1 执行。

表5.3.1 橡胶式伸缩装置评定
评定指标 评定标度
0 1 2 3
橡胶板老化破损 轻度老化 破损范围小于10% 破损范围介于10% ~30% 破损范围大于30%
渗漏水 - 局部滴漏，范围小于10% 渗漏范围介于10% ~50% 渗漏范围大于50%
锚固螺栓松动、脱落 - 数量小于10% 数量介于10% ~30% 数量大于30%

5.3.2 模数式伸缩装置结构性缺损评定应按表5.3.2 执行。

表5.3.2 模数式伸缩装置评定
评定指标 评定标度
0 1 2 3
堵塞 - 少量堵塞 严重堵塞 -
止水带老化破损 - 老化开裂；破损、脱落、渗漏水范围小于10% 破损、脱落、渗漏水范围介于10% ~30% 破损、脱落、渗漏水范围大于30%
钢件损坏 - - 局部变形；组件异常 翘曲；断裂
锚固区损伤 - 纵向裂缝；混凝土破损范围小于10% 混凝土破损范围介于10% ~30% 混凝土破损范围大于30%
纵梁间高差 - 高差小于5mm 高差介于5 ~10mm 高差大于10mm
支承元件损伤 - 少量缺损 弹性支承元件严重剪切变形或刚性支承元件松动数量大于20% 支承元件破损、脱空或脱落数量大于10%
横梁损伤 - 磨损 变形不大于5mm 变形大于5mm；断裂

注：多缝式伸缩装置中梁松动、异响或异常变位时检查支承元件和横梁确认损伤情况，支承元件包括弹性支承元件和铰链等刚性支承元件。

5.3.3 梳齿板式伸缩装置结构性缺损评定应按表5.3.3 执行。

表5.3.3 梳齿板式伸缩装置评定
评定指标 评定标度
0 1 2 3
堵塞 - 少量堵塞 严重堵塞 -
止水带/导水管老化破损 - 老化开裂；破损、脱落、渗漏水范围小于10% 破损、脱落、渗漏水范围介于10% ~30% 破损、脱落、渗漏水范围大于30%
梳齿板缺损 - 相邻齿板高差小于2mm 相邻齿板高差介于2 ~5mm；齿板缝隙不均匀 相邻齿板高差大于5mm；卡齿、断裂或脱落
锚固区损伤 - 纵向裂缝；混凝土破损范围小于10% 混凝土破损范围介于10% ~30% 混凝土破损范围大于30%
对接齿板高差 - 高差小于5mm 高差介于5 ~10mm 高差大于10mm
锚固螺栓缺损 完好或轻度锈蚀 锚固胶缺失 松动或脱落数量不大于30% 松动或脱落数量大于30%
支承托架缺损 - 脱焊、局部松动数量小于10% 脱焊、局部松动数量介于10% ~30% 脱焊、局部松动数量大于30%；有明显变形

注：锚固螺栓松动或脱落比例以单块梳齿板锚固螺栓计算。

表5.3.4 无缝式伸缩装置评定

0 1 2 3
渗漏水 - 局部渗漏 大面积渗漏 -
开裂 - 局部开裂 较大范围的开裂 完全裂开；弹性体暴露、损坏

5.4 防撞护栏

5.4.1 混凝土护栏结构性缺损评定应按表5.4.1 执行。

表5.4.1 混凝土护栏评定
评定指标 评定标度
0 1 2 3
钢扶手缺损 - 锈蚀长度不大于 10%；变形小于 10mm 锈蚀长度大于 10%；变形介于 10 ~30mm 变形大于 30mm
钢筋锈蚀 - - 主筋外露锈蚀 主筋严重锈蚀
竖向裂缝 - 宽度小于 0.2mm 宽度介于 0.2 ~0.5mm 宽度大于 0.5mm
混凝土破损 - 局部破损 大面积破损，钢筋外露 局部倾斜或倒塌

注：钢扶手指混凝土护栏顶部设置的非有效防撞构件，变形包括局部变形和整体变形。

5.4.2 金属梁柱式护栏结构性缺损评定应按表5.4.2 执行。

表5.4.2 金属梁柱式护栏评定
评定指标 评定标度
0 1 2 3
锈蚀 - 氧化皮覆盖，几乎没有铁锈 发生锈蚀且氧化皮已开始剥落 氧化皮因锈蚀而剥落，有轻微点蚀
局部变形 - 变形小于10mm 变形介于10 ~20mm 变形大于20mm
杆件、连接缺失 - 个别螺栓松动 少量螺栓松动、脱落；横向杆件缺失 大量螺栓松动、脱落；立柱缺失
立柱锚固缺损 - - 螺栓松动、脱落 大量螺栓松动、脱落；底座局部松动

5.4.3 组合式护栏结构性缺损评定应按表5.4.3 执行。

表5.4.3 组合式护栏评定
评定指标 评定标度
0 1 2 3
钢件锈蚀 - 氧化皮覆盖，几乎没有铁锈 发生锈蚀且氧化皮已开始剥落 氧化皮因锈蚀而剥落，有轻微点蚀
钢件缺损 - 个别杆件变形 多处杆件变形 杆件缺失
锚固缺损 - 个别螺栓松动 少量螺栓松动或脱落 大量螺栓松动或脱落
混凝土竖向裂缝 - 宽度小于0.2mm 宽度介于0.2 ~0.5mm 宽度大于0.5mm
混凝土破损、变形 - 局部破损 大面积破损，钢筋外露 局部倾斜或倒塌

表5.4.4 波形梁钢护栏评定
评定指标 评定标度
0 1 2 3
锈蚀 - 面积不大于所在面面积的10% 面积大于所在面面积的10% -
波形钢板局部变形 - 变形小于20mm 变形介于20 ~50mm 变形大于50mm
波形钢板整体变形 - 变形小于50mm 变形介于50 ~100mm 变形大于100mm
立柱变位 - - 变位不大于50mm 变位大于50mm
防阻块损伤 - 变形小于构件尺寸的5% 变形介于构件尺寸的5% ~10% 变形大于构件尺寸的10%；脱落
螺栓缺失 - - 缺失数量不大于5% 缺失数量大于5%

表5.4.5 缆索护栏评定
评定指标 评定标度
0 1 2 3
钢丝绳 - 表面轻度锈蚀 表面大量锈蚀或单根钢丝绳松弛 两根以上钢丝绳松弛或有钢丝绳缺失
立柱锈蚀 - 表面轻度锈蚀 锈蚀膨胀面积不大于构件面积的5% 锈蚀膨胀面积大于构件面积的 5%
立柱松动变形 - 个别杆件轻度变形 个别杆件明显变形 少量杆件明显变形或个别杆件显著变形
立柱断裂 - - - 有杆件断裂

5.5 栏杆和人行道

5.5.1 栏杆结构性缺损评定应按表5.5.1 执行。

表5.5.1 栏杆评定
评定指标 评定标度
0 1 2 3
剥落露筋 - 局部混凝土剥落 多处混凝土剥落，钢筋外露锈蚀 混凝土剥落，钢筋严重锈蚀
开裂 - 个别杆件开裂 局部杆件开裂，尚不影响安全 大量杆件开裂或有杆件断裂
松动、变形 - 个别杆件松动 局部杆件变形，尚不影响安全 局部、整体变形
锚固缺陷 - - 个别立柱或挑梁松动 较多立柱或挑梁松动

路缘石缺损 磨损 缺角、钢筋锈蚀 混凝土剥落、钢筋锈蚀 断裂、缺失

5.6 排水系统

5.6.1 排水系统结构性缺损评定应按表5.6.1 执行。

表5.6.1 排水系统评定
评定指标 评定标度
0 1 2 3
排水口堵塞 - - 数量不大于总量的30% 数量大于总量的30%
设置缺陷 - - 排水侵蚀梁体 排水侵蚀导致防护劣化；排水口高于桥面铺装
