12 附属构造结构性缺损评定
========================================

.. raw:: html

  <h2 id="test111">12 附属构造结构性缺损评定</h2>

12.1 一般规定
----------------------

.. raw:: html

 <p style="text-align:justify"><a href="#id12.1.1"> 12.1.1</a> <span id="id12.1.1"> 附属构造应对河床及调治构造物、翼墙、锥坡、护坡、其他附属设施等构件进行结构性缺损评定。</span></p>
 <p style="text-align:justify"><a href="#id12.1.2"> 12.1.2</a> <span id="id12.1.2"> 河床及铺砌缺损应计入所在桥跨评定，导流堤、丁坝等调治构造物缺损应计入受影响桥跨评定。</span></p>
 <p style="text-align:justify"><a href="#id12.1.3"> 12.1.3</a> <span id="id12.1.3"> 翼墙、锥坡、护坡缺损应计入相邻边跨评定。</span></p>
 <p style="text-align:justify"><a href="#id12.1.4"> 12.1.4</a> <span id="id12.1.4"> 其他附属设施缺损应计入附属构造所在桥跨评定。</span></p>
