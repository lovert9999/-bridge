附录 A 专项检查

附录 A 专项检查

A.0.1 构件可能存在内部缺损影响正常功能时，应优先采用无损检测技术查明影响程度和原因并提出处治建议。无损检测技术无法实现时，应经过可靠论证采用局部破损方法检测。

A.0.2 桥面排水不畅，有明显积水时，应按下列规定开展专项检查：

  1. 测量桥面线形，桥面纵、横坡设置情况，积水区域加密测点。
  2. 检查泄水孔位置及排水是否通畅。
  3. 分析积水原因，提出处治建议。

A.0.3 台后明显跳车时，应按下列规定开展专项检查：

  1. 测量桥路衔接处50m范围纵断面高程，分析桥路高差状况。
  2. 核查竣工资料，明确台后搭板设置情况。
  3. 必要时对台后路基进行勘探，掌握路基填筑状况、含水率等。
  4. 分析跳车产生原因，提出处治建议。

A.0.4 混凝土构件控制截面裂缝宽度超限，或在活载作用下裂缝处于开合状态时，应按下列规定开展专项检查：

  1. 绘制裂缝展开图，标明裂缝位置、走向和宽度，分析裂缝内外（或左右）侧的对应关系。
  2. 与历次检查成果对比分析，明确裂缝发展规律。
  3. 测量主要裂缝深度，必要时局部钻孔或取芯，掌握裂缝在混凝土内部的扩展方向。
  4. 分析裂缝成因，必要时结合结构检算提出处治建议。

A.0.5 混凝土构件因环境因素、渗漏水长期侵蚀等情况，内部钢筋锈蚀发生可能性较高时，应按下列规定开展专项检查：

  1. 根据锈蚀发生的条件，选择适当测区。
  2. 采用半电池电位法测量钢筋锈蚀电位。
  3. 绘制等电位图，锈蚀显著时扩大测区。
  4. 分析锈蚀成因，提出处治建议。

A.0.6 预应力混凝土构件存在顺钢束开裂，且伴有渗水泛碱现象时，宜开展注浆密实度检测，提出处治建议。

A.0.7 预应力混凝土构件有明显下挠、开裂，需判断产生原因时，宜采用横张法或其他可靠方法开展有效预应力检测，提出处治建议。

A.0.8 上部结构主要承重构件承载能力、铰缝及横向联系传力功能明显不足时，应按现行《公路桥梁承载能力检测评定规程》（JTG/T J21）或《公路桥梁荷载试验规程》（JTG/T J21-01）的规定开展检测评定，提出处治建议。

A.0.9 主拱圈有横向贯通开裂、拱圈明显变形或拱脚明显位移时，应按下列规定开展专项检查：

  1. 测量主拱圈及拱上结构尺寸，计算各部分恒载分布。
  2. 调查桥梁通行荷载情况。
  3. 测量拱轴线及拱脚位移值。
  4. 检算主拱圈内力分布。
  5. 判定承载能力，提出处治建议。

A.0.10 加固构造与原结构剥离、钢构件严重锈蚀等导致加固构造与原结构不能共同受力、预应力组件变形或预应力明显损失导致加固效果下降时，应按下列规定开展专项检查：

  1. 详细检查加固构造的缺损范围。
  2. 结合设计文件检算加固构造的有效性。
  3. 必要时，针对加固构造开展荷载试验。
  4. 判定承载能力，提出处治建议。

A.0.11 拉吊索内层防护破损、开裂，索体有锈蚀发生可能时，应按下列规定开展专项检查：

  1. 局部拆除失效部位防护层，检查锈蚀情况。
  2. 局部拆除索体底端防护层，检查锈蚀情况。
  3. 拆除锚头防护盖，检查渗漏水及锈蚀情况。
  4. 分析拉吊索缺损范围及程度，提出处治建议。

A.0.12 拉吊索索力偏差大于 10%时，应按下列规定开展专项检查：

  1. 测试全桥索力分布。
  2. 测试桥面线形。
  3. 检算全桥拉索安全系数。
  4. 评估索力重分布对主梁受力的影响，提出处治建议。

A.0.13 支座系统产生严重剪切变形或滑动时，应按下列规定开展专项检查：

  1. 根据支座缺损情况逐一测量全跨、全联或全桥支座变形或位移量。
  2. 绘制支座变形或位移图，判断梁体位移趋势。
  3. 根据梁体位移趋势检查梁端位移、固定支座缺损情况。
  4. 检查固定支座所在桥墩变形和裂缝分布。
  5. 分析缺损产生原因及影响程度，提出处治建议。

A.0.14 桥墩或桥台台身产生明显倾斜、变位、水平向开裂时，应按下列规定开展专项检查：

  1. 按现行《公路桥梁承载能力检测评定规程》（JTG/T J21）要求开展桥梁恒载变异状况调查。
  2. 材料参数、截面参数调查。
  3. 变形、变位状况调查。
  4. 分析缺损产生原因及影响程度，提出处治建议。

A.0.15 系梁与桩、柱连接处两端出现规则竖向裂缝时，应按下列规定开展专项检查：

  1. 详细检查开裂情况。
  2. 测量墩台各节段倾斜、变形情况，必要时局部开挖埋置部分。
  3. 分析缺损产生原因及影响程度，提出处治建议。

A.0.16 扩大基础埋深不明或显著冲刷时，宜采用钻孔取芯法或其他可靠方法探明基底位置，依此检算地基承载力并提出处治建议。

A.0.17 桩基础桩头外露明显时，应查阅基础类型和埋置深度，并与设计局部冲刷深度对比分析，评估桩基的竖向承载力和抗弯承载力。缺乏设计资料时，经勘探确认地质条件及基础埋深，依此检算基桩承载力并提出处治建议。

A.0.18 桩基础外露长度过大时，应结合原设计计算结果判定桥墩稳定性，无相关资料时应检算桥墩承载力和稳定性。

A.0.19 河床断面冲刷下切严重或主河槽明显变迁时，应按下列规定开展专项检查：

  1. 测量桥位上下游桥侧河床断面。
  2. 测量桥位上下游50m、100m河床断面。
  3. 结合历次检查成果分析河床变迁规律。
  4. 结合设计文件分析河床冲刷对结构的影响，提出处治建议。

A.0.20 隐蔽构件可能有明显缺损或功能异常时，应采用可靠方案局部拆除防护构造或遮挡物，明确缺损状况、功能状况及影响状况，提出处治建议。处治完成后应恢复防护构造或遮挡物。
