4.1 配筋混凝土构件
-----------------------------------
.. raw:: html

 <p style="text-align:justify"><a href="#id4.1.1"> 4.1.1</a> <span id="id4.1.1"> 配筋混凝土构件耐久性缺损应评定下列内容：</span></p>

 <ol>
 <li> 耐久性缺陷应评定蜂窝、麻面、孔洞、网状裂缝等。</li>
 <li> 耐久性损伤应评定水侵蚀、泛碱析白、侵蚀劣化、露筋锈蚀、顺筋裂缝等。</li> 
 </ol>

 <p style="text-align:justify;" >条文说明：<br/>蜂窝、麻面指混凝土构件由于模板、脱模时机不当或混凝土质量等施工原因造成的外观质量缺陷。蜂窝表现为表面缺失水泥浆形成的局部蜂窝样粗骨料外露；麻面表现为混凝土表面局部缺浆、粗糙或密集小凹坑。<br/> 孔洞指混凝土构件由于施工时振捣不足、跑浆等原因造成的外观质量缺陷，表现为深度大于构件保护层厚度的孔穴。 <br/>网状裂缝指混凝土构件受早期温度应力、收缩徐变或后期侵蚀等因素导致的外观缺陷，表现为深度小于10mm、宽度小于0.1mm呈网状分布，且未引发钢筋锈蚀的状态。</p>

4.2 钢构件
-----------------------------------
.. raw:: html

 <p style="text-align:justify"><a href="#id4.2.1"> 4.2.1</a> <span id="id4.2.1"> 钢构件耐久性缺损应评定下列内容：</span></p>
  <ol>
 <li> 耐久性缺陷应评定防腐涂料涂层缺陷、金属涂层缺陷、漏涂等。</li>
 <li> 耐久性损伤应评定表层防护劣化、底层防护劣化等。</li>
 </ol>
